# DBMS Project

A simple hospital management web project with HTML front-end and a Node.js backend.

## Features
- Add/view doctors and patients
- Manage appointments, billing, and medical records
- Simple authentication for admin and patients

## Prerequisites
- Node.js (for the server)
- Git (optional, for pushing to GitHub)

## Install & Run
1. Install dependencies (if any):

```bash
npm install
```

2. Run the server (if you're using the Node server):

```bash
node server.js
```

3. Open the front-end in your browser:

- Navigate to `http://localhost:3000` (or the port your `server.js` uses)
- Or open `index.html` directly in a browser

## Project Structure
- `server.js` — Node server (if used)
- `package.json` — project metadata and dependencies
- `index.html` — main landing page
- `admin-dashboard.html`, `patient-dashboard.html`, `viewdoctors.html`, `viewpatients.html`, etc. — app pages
- `css/style.css` — styles

## Usage
- Log in as admin via the admin login page to manage doctors, patients, appointments and billing.
- Patients can log in via the patient login page to view records and appointments.
